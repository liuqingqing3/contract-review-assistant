# 中英文货物采购合同审查助手

**刘清清｜个人实践作品｜AI 辅助开发｜本地原型 v0.3.4**

将法律审查思路转化为可操作的 AI 辅助工作流程：从买方或卖方立场识别合同问题，核对中英文版本的实质差异，并由使用者复核、编辑及导出建议。

## 项目背景

作为法学专业留学生，我在学习中需要阅读、分析大量中英文法律材料。本项目以普通货物采购为场景，探索如何把审查范围、原文依据和人工判断结合到一个可运行的工具中，而不仅是让模型生成一段分析。

## 核心功能

- **合同审查**：选择买方或卖方立场，输入合同及相关附件文字，选择中文或英文报告。
- **十二类审查范围**：主体与授权、货物与供货范围、价格付款与发票、交付与风险承担、验收与异议、质量质保与售后、变更与履约协作、知识产权保密与数据、违约赔偿与免责、生效期限与退出、法律适用与争议解决、通知与文件一致性。
- **中英文一致性核对**：比较金额、数量、期限、义务、责任、否定表述及遗漏等实质差异，不预设某一语言版本优先。
- **可核对的结果结构**：原文、影响、待确认事项、修改方向和拟修改文本；显示风险等级及分级理由，信息不足时允许标注待评估。
- **人工复核**：保留、不采纳、编辑建议、撤销处理及状态导航；可导出 TXT 或通过浏览器打印为 PDF。
- **操作保护**：两种功能分别暂存当前页面中的材料及报告；修改材料前提示报告失效。刷新或关闭页面仍会丢失内容，请先导出。

## 我的贡献与 AI 分工

我负责应用场景、用户立场、审查范围和结果结构的设计，根据试用反馈持续调整交互，并关注输出是否对应原文、是否混淆商业风险与法律效力、是否擅自补充交易条件。

开发过程中借助 Codex 辅助实现代码、排查错误和执行自动化检查；运行时通过 DeepSeek-V4-Pro API 生成自定义合同的审查结果。项目不是全部手工编码，也不是经专业机构认证的合同审查系统。

## 关键设计与迭代

1. **区分示例与真实分析**：示例模式展示预先编写的结果；AI 模式根据输入调用模型。自定义材料不会套用预设答案，模型失败时也不会用示例替代结果。
2. **处理输出截断**：曾遇到思考占用输出额度、报告未完整生成的问题。定位后关闭深度思考并要求简洁输出，保留长度上限、完整性检查及失败提示；不自动重试。该调整是生成长度与分析方式之间的取舍，并不保证准确性提高。
3. **保留原文依据**：程序检查模型引文能否在输入材料中逐字找到，并检查输出结构。能匹配原文不代表分析正确，仍需人工复核。
4. **保留人工决策权**：风险等级仅用于复核排序，不等同于违法或无效结论；对待确认交易条件使用占位提示，不替使用者作最终决定。

## 如何体验

### 方式一：无需密钥，查看交互样例

在仓库首页选择 **Code → Download ZIP**，解压后打开根目录的 `index.html`。保持“预设示例”模式，选择立场并载入示例，即可体验报告、风险标记、人工处理与导出流程。

此模式不调用 AI、不产生模型费用，仅用于展示设计与交互。

### 方式二：使用自己的密钥进行 AI 审查

1. 安装 [Node.js](https://nodejs.org/) 22 或更高版本，无需安装其他程序依赖。
2. 在解压目录运行启动文件：Mac 使用 `启动合同助手.command`，Windows 使用 `启动合同助手.cmd`。也可在该目录的终端运行：

   ```sh
   node backend/local.mjs
   ```

   Mac 若无法直接执行启动文件，可在该目录运行 `zsh 启动合同助手.command`。
3. 保持启动窗口打开，在浏览器访问 `http://127.0.0.1:4317`，点击“本地密钥配置”，填写自己的 DeepSeek API key。
4. 选择 AI 模式，输入有权发送的脱敏材料，确认发送后手动开始审查。费用由该密钥对应账户承担。
5. 结束时在启动窗口按 Control+C 停止服务。请不要同时启动多个版本。

`127.0.0.1` 是使用者自己的电脑地址，不是公开演示网站。本项目无需购买服务器即可本地运行。

## 数据与调用边界

- 密钥仅保存在本地服务进程内存中，重启后需重新配置；不需要向作者提供密钥。
- AI 审查会将材料发送至 DeepSeek，请勿输入无权发送的合同或敏感信息。本工具不主动将合同及报告保存到磁盘；导出文件由使用者自行保管。
- 每次材料合计最多 20,000 字符，输出上限 8192 tokens。每个运行目录最多 20 次尝试，失败也计入；这是本地防误调用限制，不是服务商额度或账户总预算。
- 页面费用仅为估算，以服务商实际账单为准。
- 运行生成的 `.private` 文件夹及任何密钥、真实合同和个人材料都不应上传仓库。提交前应检查文件；不能只依赖忽略规则。

## 技术结构与验证

| 文件 | 用途 |
| --- | --- |
| `public/v3.html` | 主界面、交互与报告展示 |
| `public/setup.html` | 本地密钥配置页面 |
| `backend/review.mjs` | 审查提示词、模型调用、结构及引文核对 |
| `backend/local.mjs` | 本地服务、访问限制及尝试次数管理 |
| `index.html` | 无 AI 的离线样例入口 |
| `test-*.mjs` / `test-*.cjs` | 模拟接口及交互逻辑测试 |

可在项目目录运行：

```sh
node test-backend.mjs
node test-local.cjs
node test-workspaces.cjs
```

Mac/Linux 的界面逻辑回归测试：

```sh
TEST_HTML=public/v3.html node test-v2.cjs
```

上述测试使用模拟接口，不产生真实模型调用费用，覆盖输入约束、错误拦截、引文匹配、风险分级、工作区状态等逻辑。它们不是浏览器视觉测试，也不是法律准确率评测。

## 当前限制与后续方向

本项目为本地原型，审查场景限定为普通货物采购及中国大陆法范围；支持英文文本不代表支持各国法律。当前未接入权威法规检索，不自动联网核验法律，不支持扫描件识别，也未完成系统性的法律准确性评测。

模型可能遗漏问题、误判风险或给出不恰当建议。后续拟完善人工标注的评测样本，比较不同模型及生成设置，并分析遗漏、误报和双语差异识别等错误案例。

**本作品用于展示 AI 辅助审查与人工复核流程，不构成法律意见，不能代替专业判断或直接作为签约依据。**
