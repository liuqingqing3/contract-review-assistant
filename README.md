# 合同审查助手 · Contract Review Assistant

面向普通货物采购场景的中英文合同辅助审查原型，将条款分析、风险提示、修改建议与人工复核组织成一个可操作的工作流程。

**作者：刘清清 / Qingqing Liu**  
**版本：v0.3.7 · 本地运行**  
**项目性质：法务 AI 产品个人实践作品，借助 AI 工具辅助开发**

> 这是一个探索法律专业判断与 AI 协作方式的产品原型，不是法律意见或自动签约工具。预设示例与实时 AI 分析有明确区分。

## 项目解决什么问题

合同审查不仅是指出“某个条款有风险”，还需要说明风险对哪一方有影响、判断依据是什么、建议如何修改，以及哪些问题仍需人工确认。

本项目以办公家具采购为具体场景，尝试将这一过程组织为：

**选择立场 → 提供合同 → 查看原文与建议 → 人工保留、编辑或不采纳 → 导出报告**

## 核心功能

| 功能 | 实现内容 |
| --- | --- |
| 买卖双方立场 | 按所代表的一方分析交易影响；示例中的付款、交货、验收等建议分别设计 |
| 12 类审查范围 | 主体授权、供货范围、价格付款、交付、验收、质量售后、变更、知识产权与数据、违约免责、期限退出、争议解决、通知及文本一致性 |
| 中英文一致性核对 | 对照金额、期限、责任范围、否定词及遗漏等实质差异，不默认某一语言优先 |
| 风险分级 | 高、中、低风险及待评估，附分级理由；区分风险程度与事项性质 |
| 原文对应 | AI 引文须在提交材料中逐字找到，并记录字符位置；这只是文本校验，不代表法律分析正确 |
| 人工复核 | 保留、不采纳、编辑建议与撤销；处理状态、数量和分类导航同步更新 |
| 中英文报告 | 操作界面保持中文，报告可选择中文或英文；原始引文不自动翻译 |
| 报告导出 | TXT 与浏览器打印/PDF，包含拟修改文本，涵盖全部事项而非仅当前筛选结果 |
| 内容保护 | 两个工作区在当前页面分别暂存；修改材料前提示报告失效，刷新或关闭前提醒 |

## 两种体验方式

### 1. 无需密钥：体验预设示例

下载项目，打开根目录 `index.html`，选择“预设示例”，载入合同并选择立场。

这一方式用于体验产品流程，结果是预先编写的设计样例，不是实时 AI 分析。修改示例或输入新合同后，不能继续套用预设结果。

### 2. 使用自己的密钥：运行真实 AI 审查

需要 **Node.js 22 或更高版本**、可访问 DeepSeek API 的网络，以及自己的 API key。无额外程序依赖。

1. Mac 运行 `启动合同助手.command`；Windows 运行 `启动合同助手.cmd`。
2. 浏览器打开 `http://127.0.0.1:4317`。
3. 点击“本地密钥配置”，填写自己的 DeepSeek API key。
4. 选择 AI 模式，输入有权发送的脱敏材料，勾选确认后手动开始审查。

也可在项目目录执行：

```sh
node backend/local.mjs
```

Mac 如无法双击启动文件，可在项目目录执行：

```sh
zsh 启动合同助手.command
```

运行时保持终端窗口打开，结束时按 Control+C。密钥只保留在当前服务进程内存中，重启后需要重新配置。模型调用费用由密钥对应账户承担。

`127.0.0.1` 是本机地址，不是公开网站链接。GitHub 仓库也不等于已部署的在线服务。

## 产品设计取舍

- **商业风险不等于违法。** 风险等级用于安排复核优先级，不能代替法律效力判断。
- **不补造交易条件。** 未确认的日期、比例、机构等使用占位内容，留待人工决策。
- **不以示例掩盖失败。** AI 失败时不返回预设样例冒充分析结果。
- **区分辅助字段异常与核心错误。** 无法识别的覆盖状态标为待人工确认，并写入报告限制；错误引文或关键字段缺失仍拦截。
- **控制无效消耗。** 不自动重试，显示接口用量与费用估算；单目录最多20次模型尝试，失败也计入。

## 实现与迭代

网页使用 HTML、CSS 和 JavaScript；本地服务使用 Node.js。后台调用 DeepSeek V4 Pro，将选定立场、报告语言、审查规则和合同材料提交给模型，再校验返回结果。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 无密钥离线示例入口 |
| `public/v3.html` | 本地服务使用的审查界面 |
| `public/setup.html` | 本地密钥配置页 |
| `backend/local.mjs` | 本地访问控制、请求调度与尝试次数管理 |
| `backend/review.mjs` | 提示词、模型调用、结构校验与引文核对 |
| `test-*.mjs` / `test-*.cjs` | 模拟接口与界面逻辑回归测试 |

迭代过程中遇到过思考占用输出额度、结构校验失败、异常关闭后启动受阻等问题。相应调整包括关闭深度思考并压缩输出、细化错误定位、将辅助状态异常降级提示，以及使用固定本机端口防止重复运行。

这些调整体现了产品可靠性与使用成本之间的取舍，不代表已解决全部模型错误。

## 我的工作与 AI 的分工

我提出使用场景与功能需求，围绕法律审查流程设计立场选择、输出结构、人工复核和报告交付方式，并通过实际试用反馈推动迭代。AI 工具辅助完成代码实现、示例初稿和自动测试。

项目并非全部代码手写；法律判断、示例措辞与模型输出仍需要人工核验。未将 AI 生成内容作为已验证的法律结论。

## 验证情况与当前限制

当前有模拟接口和界面逻辑测试，覆盖输入校验、引文匹配、错误分类、未知覆盖状态的保守处理、工作区切换、打印内容构建和费用保护等场景。

```sh
node test-backend.mjs
node test-local.cjs
node test-workspaces.cjs
```

Mac/Linux 的界面逻辑测试：

```sh
TEST_HTML=public/v3.html node test-v2.cjs
```

以上测试不调用付费模型。项目进行过人工 API 试用，但尚未建立系统性的真实合同评测集，不能据此声称达到特定准确率、稳定性或提速幅度；浏览器打印分页也尚未完成系统验证。

当前仅面向普通货物采购及中国大陆法范围的辅助复核，不联网检索或核验法规，不支持扫描件识别、多国法律自动适用或自动签约。长材料和复杂交易仍可能遗漏、误判或返回不合格结果。

AI 模式一次生成一种报告语言，切换语言后重新生成会再次调用模型。用户编辑与原始引文保留其输入语言，不自动翻译。

## 隐私与使用提示

- 仅使用虚构或有权提供的脱敏材料；AI 模式下材料会发送给 DeepSeek。
- 程序不保存合同和报告历史，刷新或关闭网页会丢失，请先导出。
- `.private` 记录本地尝试次数，不应上传到仓库；升级时保留该文件夹，不要清空次数记录。
- 20次限制属于单个运行目录，不是账户级费用上限。界面费用为估算，实际以服务商账单为准。
- 不要上传 API key、真实合同、账单、个人信息或运行后生成的私人文件。
- 拟修改文本仅供讨论，必须补全占位内容并核对完整合同后再使用。

后续计划：建设带人工参考答案的小型评测集，记录误报与漏报，并进一步评估输出质量、响应时间及使用成本。
