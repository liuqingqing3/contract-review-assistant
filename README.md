# 合同审查助手 v0.3.4 · 本地版

本次更新：处理提示移到右侧统计下方；双语核对增加全部/未处理/已处理状态导航和数量；处理后直接跳转，不等待滚动动画；AI 成功报告显示实际请求用时。保留 v0.3.3 的关闭深度思考与简短报告设置。尚未实测真实 API 提速幅度。

请先停止旧服务，再启动本版。浏览器标题应显示 v0.3.4；若仍显示 v0.3.2，说明尚未打开新版服务。示例模式不调用模型，不应等待模型生成。不要同时启动多个版本。

本作品用于展示合同审查与人工复核流程，不是法律意见，不应直接用于签约决策。

## 不配置 AI 也能看

解压后打开 index.html，保持“预设示例”模式，选择立场，载入试用示例并生成报告。样例结果为预先编写，不是实时 AI 分析；自定义合同必须使用 AI 模式。可体验风险分级、保留/不采纳/编辑建议和报告导出。

## 使用自己的 AI

1. 电脑需安装 Node.js 22 或更高版本（https://nodejs.org）。不需要安装其他程序依赖。需要可连接 DeepSeek API 的网络。
2. Mac 双击“启动合同助手.command”；Windows 双击“启动合同助手.cmd”。若 Mac 不允许执行，可在终端进入解压文件夹后运行 `zsh 启动合同助手.command`。也可以直接运行 `node backend/local.mjs`。
3. 保持启动窗口打开，在浏览器访问 http://127.0.0.1:4317 。这只是自己电脑的地址，不能作为对外展示链接。
4. 点击“本地密钥配置”，填写自己的 DeepSeek API key。密钥仅保存在当前服务进程内存中，重启后需重新配置；配置本身不调用模型。
5. 选择“AI 审查”、立场和语言，输入有权发送的脱敏材料，勾选确认后手动开始。费用由所填密钥对应账户承担。不需要向作品作者提供密钥。
6. 结束时，在启动窗口按 Control+C 停止服务。

不要同时启动两个版本。如提示已有服务，请先关闭旧服务；不要直接删除锁文件或运行记录。

## v0.3.3 修复

此前一次响应的 8192 输出 tokens 中有 7001 用于思考，报告正文剩余额度不足而被截断。本版仍使用 deepseek-v4-pro，但设置 thinking.type=disabled，不再设置 reasoning_effort；输出上限仍为 8192。提示词要求简短字段、合并重复问题、明确未充分覆盖的部分。并非预先编写自定义合同的答案，分析仍由模型根据输入生成。

关闭思考是控制生成长度的取舍，不保证分析更准确。仍可能出现截断、遗漏、引文或格式错误；不完整报告继续拦截，不自动重试，不用预设样例替代失败结果。对真实法律规则和分级理由仍须人工核验。

保留 v0.3.2 的风险等级与理由、分级数量、双工作区临时保留和丢失报告前确认。刷新或关闭网页仍会丢失材料与报告，请先导出。不会保存合同历史。

## 费用与数据

- 单次材料合计最多 20,000 字符；每个运行目录最多 20 次模型尝试，失败也计入。此限制不是账户总预算；换新目录不会继承旧目录计数。
- 已有用户升级：先停止旧服务，将本包的 public、backend 和启动文件复制到原运行目录替换对应程序文件，保留原 .private 文件夹，继续使用原目录的次数记录。本包不含任何人的 .private。
- 本地服务仅监听 127.0.0.1，不适合作为公网服务直接开放。发送 AI 请求时，材料会传给 DeepSeek；未运行 AI 时样例操作不发送材料。
- 界面费用为估算，不是实际账单，实际金额以服务商账单为准。

## 交付与复现

建议提交：本压缩包 + 2–3 分钟演示视频 + 一份脱敏示例报告；自行配置 AI 是可选复现方式，不应成为理解作品的唯一入口。

技术结构：public/v3.html 是网页，backend/review.mjs 负责模型提示词、调用及输出核验，backend/local.mjs 是本地服务。根目录 index.html 只用于无 AI 的离线预览。

源代码可放入 GitHub repository（代码仓库）。只上传本交付包内的程序和说明；运行后生成的 .private、密钥、账单、真实合同、个人材料均不要上传。公开仓库的代码可被他人查看；仓库本身不等于部署好的网站。

## 验证范围

本版提供模拟接口自动测试，检查请求设置、失败拦截、原文核对、风险分级、工作区保留和本地访问限制。测试不会调用真实付费模型。未将模拟测试表述为真实模型准确率或真实 API 成功率；修改后的真实效果仍需使用者手动测试。

测试命令：`node test-backend.mjs`、`node test-local.cjs`、`node test-workspaces.cjs`。界面回归测试：Mac/Linux 运行 `TEST_HTML=public/v3.html node test-v2.cjs`。
